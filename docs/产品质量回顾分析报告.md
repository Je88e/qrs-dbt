**示例指标：水分**

> **[数据来源]**: LIMS

|**标准 / 批号**|**批次 A**|**批次 B**|
|---|---|---|
|应不得过 XX|Value 1|Value 2|

**过程能力分析 (Cpk/Ppk)**

当 n ≥ 25 时，进行以下分析：

1. **正态性检验**：根据 P 值判定。
    
    - P ≥ 0.5：进行正态分布能力分析。
        
    - P < 0.5 但其他分布 P ≥ 0.5：选取 P 值最大的分布进行分析。
        
    - 所有分布 P < 0.5：直接计算 Cpk。
        

**Cpk 计算公式：**

$$Cpk = \min \left( \frac{USL - \mu}{3\sigma}, \frac{\mu - LSL}{3\sigma} \right)$$
