# Vue 3 列级数据血缘可视化组件开发计划

## 1. 背景与目标
- 面向 QRS（GxP 合规药企数据仓库）的 dbt 项目，基于 `lineagex` 生成的 `output.json`。
- 提供端到端（raw → staging → business → reports）的**跨层级表级 + 列级血缘可视化**。
- 支持影响分析、根因分析、审计佐证等典型 GxP 使用场景。

## 2. 数据源与结构概述
- 数据来源：`qrs/dbt_packages/lineagex/output/output.json`。
- 顶层为字典：`{ [tableId: string]: LineageRawNode }`。
- 每个节点包含：`table_name`、`tables`、`columns`、`upstream_tables`、`downstream_tables`、`is_model`。
- 通过命名约定派生：层级（raw/stg/int/dim/fct/report）、域（ERP/MES/LIMS/QMS/SCADA/PV）。
- 额外衍生结构：表级图（节点 = 表/模型，边 = 表依赖），列级图（节点 = 表.列，边 = 列依赖）。

## 3. 技术栈与整体架构
- 前端框架：Vue 3 + Composition API + TypeScript。
- 图引擎：AntV G6（支持大规模关系图、分层布局、路径高亮）。
- 构建工具：Vite。
- 状态管理：Pinia 或组合式函数 + provide/inject（由项目自定）。
- UI 组件库：**不强制指定**，由实际开发团队根据项目统一的设计规范与技术栈决定。
- 部署方式：作为独立前端模块集成到 QRS 前端或运维控制台中。

## 4. 视图模式与跨层级展示能力
- **全局跨层级视图（默认）**：一次性加载 raw、staging、intermediate、business、reports 全部节点。
- 节点按层级（raw → stg → int → dim/fct → report）进行分层布局，可在一个视图中看到端到端数据流。
- 支持以任意模型为“起点”，高亮其到终端报表或源表的完整路径。
- 层级显示控制：通过开关控制各层级的可见性，仅影响可视化，不改变底层血缘计算。
- 视图模式：
  - 表级图模式：节点 = 表/模型，边 = 表依赖。
  - 列路径模式：只渲染选中列相关的局部列级路径（跨层级）。

## 5. 多选与混合视图能力
- 支持**多选节点**：用户可在不同层级中手动选择多个模型/表，如一个 raw 表 + 若干 staging/维度/事实表。
- 维护 `selectedTables`、`selectedColumns` 集合，支持“累积选择”和“清空选择”。
- 基于多选集合构建**混合子图**：
  - 计算所有选中表的上下游 N 层依赖的并集。
  - 支持只看上游、只看下游或双向。
  - 在主图中仅渲染该子图，形成“混合视图”，不局限于单一路径或单一层级。
- 多选列级血缘：
  - 针对多个列（来自不同表），统一展示其上游来源和下游影响的合并路径。
  - 在路径面板中按“列分组”或“终端表分组”显示。

## 6. 组件划分与职责
- `ColumnLineageExplorer.vue`（主容器）：
  - 负责加载/解析 `output.json`，维护全局状态，协调子组件。
  - 提供对外 API：聚焦指定表/列、设置筛选条件、导出当前视图等。
- `LineageGraph.vue`（图渲染组件）：
  - 封装 G6 实例，渲染表级图或局部列级路径图。
  - 支持节点/边点击、高亮、缩放、拖动、路径高亮等交互。
- `LineageControls.vue`（交互控制）：
  - 图层（raw/stg/dim/fct/report）开关，上下游深度控制。
  - 视图模式切换（表级/列路径），布局复位，自动缩放。
- `LineageSearchPanel.vue`（搜索与筛选）：
  - 表名/列名搜索，层级/域过滤。
  - 多选模式管理（添加/移除选中节点）。
- `LineageNodeDetail.vue`（节点详情）：
  - 展示表/模型 metadata、上/下游表、全部列列表。
  - 列点击触发列级血缘追踪和路径高亮。
- `LineagePathInspector.vue`（路径与影响分析）：
  - 针对单列或多列展示上/下游路径树及端到端路径。
  - 与主图联动以高亮相应节点/边。

## 7. 核心功能列表
- 表级功能：
  - 全局跨层级 DAG 展示，支持层级/域过滤。
  - 上/下游 N 层展开/折叠，路径高亮。
  - 多选模型构建混合子图视图。
- 列级功能：
  - 单列上游追溯（源表级）与下游影响分析（终端报表）。
  - 多列联合影响分析和路径可视化。
- GxP 相关：
  - 仅可视化展示，不在前端修改血缘数据。
  - 在界面显著位置展示 `output.json` 生成时间和版本上下文。
  - 支持当前视图导出为图片，用于审计记录。

## 8. 开发阶段与里程碑
- 阶段 1：需求细化与技术预研（0.5–1 周）——确认业务场景、完成原型验证。
- 阶段 2：数据解析和血缘查询核心库实现（1 周）——输出可测试的算法模块。
- 阶段 3：基础表级图视图（1–1.5 周）——完成全局 DAG 渲染与基本交互。
- 阶段 4：节点详情、列级血缘与路径面板（1.5–2 周）。
- 阶段 5：搜索/筛选、多选混合视图与路径高亮（1–1.5 周）。
- 阶段 6：性能优化（子图渲染、缓存、虚拟列表、Web Worker）（1–2 周）。
- 阶段 7：GxP 增强、测试与文档完善（1–2 周）。

## 9. 性能与可扩展性原则
- 始终以“子图渲染”为原则：仅渲染当前筛选和多选上下文相关的节点/边。
- 列级血缘严格限定为局部路径，不绘制全局列级大图。
- 使用索引和缓存提升路径查询与影响分析性能。
- 对长列表（列列表、搜索结果）采用虚拟滚动。
- 为布局结果提供缓存与快照，避免反复全量布局计算。
- 为重计算操作预留将来迁移到 Web Worker 的空间。
